## 📌 Project Overview
A clean, interactive personal developer portfolio featuring a professional profile header, categorized skill badges, project cards, and smooth navigation.

---

## 🚀 Key Features
- **Modern Hero Section:** Profile presentation with direct links to professional profiles.
- **Dynamic Interactions:** Lightweight JavaScript handling smooth scroll and active link highlights.
- **Modular Stylesheet:** Clean CSS variables and flexbox/grid containers.
